# Trabalho-de-Rasi

Neste trabalho, realizei o desenvolvimento e a documentação técnica do processo de modernização de um ambiente de testes, transitando de uma instalação manual para uma infraestrutura baseada em Docker. Inicialmente, configurei uma máquina virtual no VirtualBox com Ubuntu Server ou Lubuntu e ajustei a placa de rede em modo Bridge ou NAT para assegurar a ligação à Internet e a comunicação com a máquina hospedeira. De seguida, identifiquei o endereço IP da máquina virtual e estabeleci uma ligação remota segura via SSH a partir do terminal da minha máquina hospedeira, garantindo que toda a administração do servidor fosse efetuada por esta via. Com a sessão remota ativa, atualizei os pacotes do sistema e verifiquei o correto funcionamento do Docker executando o contentor de teste `hello-world`.

Na etapa relativa à aplicação web, estruturei o projeto criando os ficheiros `app.py` e `requirements.txt`, e configurei o `Dockerfile` utilizando obrigatoriamente a imagem de base `python:3.14-slim`. Efetuei o *build* da imagem Docker e executei o contentor em segundo plano com o mapeamento da porta 5000, validando o acesso inicial à aplicação no navegador. Para cumprir o desafio de expansão da aplicação, alterei o código em `app.py` de modo a incluir novas rotas (`/sobre` e `/contato`), personalizando cada uma com diferentes títulos e estilos em HTML. Reconstruí a imagem e reiniciei o contentor para comprovar que as novas páginas e layouts estavam a funcionar corretamente.

Por fim, documentei todo este procedimento num relatório técnico em formato PDF, incluindo explicações detalhadas sobre os comandos utilizados e respetivas capturas de ecrã (*prints*) de cada etapa. Além disso, criei o meu repositório individual no GitHub com um ficheiro README a registar os primeiros passos no projeto, disponibilizando a respetiva ligação na introdução do relatório final.
